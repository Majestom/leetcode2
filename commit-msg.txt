Scaffold Vite + React + TS

Stage 1 of the Pattern Practice build (see spec.md §16).

- Vite 8 + React 19 + TypeScript project at the repo root
- Plain CSS rather than the Tailwind setup described in spec.md §12: src/styles/globals.css holds the reset and a small set of CSS custom properties (colours, fonts), and per-component styling uses CSS modules
- App.tsx renders the two-column shell (header, pattern sidebar, main column) as an empty layout via App.module.css; the panels arrive in later stages
- .gitignore covers node_modules, dist, editor dirs and .claude/

`npm install && npm run dev` serves on http://localhost:5173. `npm run build` passes.
